# Task 1: Flashcard Quiz App

**Domain:** App Development
**Internship:** CodeAlpha — Month 1

## Overview
A flashcard quiz web app for studying. Users can add, edit, delete flashcards (question/answer), navigate with Prev/Next, flip to reveal answer, and "Show Answer" button. Data persists via localStorage. Clean, modern UI.

## Tech
HTML, CSS, JavaScript (responsive web app). LocalStorage for persistence. Lucide icons.
